# Eight identity — approval preview

Open http://localhost:5173/brand-preview/index.html after npm run dev.
This page is separate from gameplay. The approved identity is applied in the live local game.

Assets: logo-full.svg, icon-eight.svg, logo-mono.svg, favicon.svg and
character-eight.svg. Character SVG uses CSS classes idle, thinking, happy, panic,
sad and win. Individual state SVGs are included for easy inspection.
Preview repeats the win animation so it can be reviewed; gameplay should run
that signature once on final-screen entry. Reduced motion suppresses animation
and displays the sideways eight for the win state. All assets are native vector.
Wordmarks retain live text with existing Space Grotesk / Arial fallback.

Brand decision supersedes octopus imagery: Octo means eight; letters occupy the
top loop, numbers the bottom, and a violet spark joins them. Application rollout was approved by the founder’s shipping instruction. Keep current game mechanics, sounds, timing and
responsive behavior when applying the approved identity.
